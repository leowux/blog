## 产品介绍

README 将 God's Eye View 描述为一个在浏览器中运行的写实 3D 地球界面：在同一画布中呈现飞机、船舶、卫星、地震、交通与公开摄像头等公开或开放数据，并可跟踪对象、切换视觉样式、生成分享链接和录制镜头路径。它提供无需 API Key 的起步路径；部分数据源、3D 地形/影像、地点搜索和语音功能则按 README 要求使用对应服务的 Key 或适用额度。

语音层是可选能力：README 明确说明它使用 OpenAI Realtime API，且 OpenAI Key 保留在服务端，浏览器只取得短期会话令牌。项目也提醒，交通是依据聚合位置数据在真实道路上模拟，摄像头姿态和火箭轨迹属于粗略估计；因此这些可视化不应被理解为精确、完整或实时的态势结论。

仓库的 `LICENSE` 是 MIT，但许可证同时注明：源码以外，内置数据集和运行时从第三方取得的数据分别归各自来源所有。这是许可范围的事实说明，不是对任何数据源可商用性、连续性或准确度的保证。

## 目标人群

从 README 的本地启动方式、逐层数据源和可扩展模块看，它适合希望把多种公开空间信号放到一个探索界面中的开发者、地理空间爱好者与可视化原型团队。典型诉求包括：检查一个地点周边的公开航空、船舶、轨道或环境信号，制作演示用的地球镜头，或以现有 layer 为模板接入自己的数据。

也适合愿意审阅数据来源、配额和密钥边界的开发者。需要把结果用于执法、安全处置、商业监控或任何高风险判断的人，不应只依赖这个前端：README 本身已标注模拟、估计和第三方配额等限制。这是基于文档和模块结构的适用性分析，并非实际用户规模、准确度或效果评测。

## 技术架构

仓库根目录包含 `src/`、`server/`、`config/`、`scripts/`、`public/` 与 Vite 配置。`package.json` 和 README 表明前端为原生 JavaScript，使用 CesiumJS 与 Vite；`src/main.js` 负责启动和图层注册，`src/ui.js` 负责面板/HUD，`src/data/` 按图层组织数据模块，`src/voice/` 管理 Realtime 会话与语音工具。`server/providers/` 按航空、船舶、空间、交通、地点、摄像头和 OpenAI 等来源拆分服务端适配器；README 说明涉及私有 Key 的 API 通过服务端代理处理。
